### 9.1.3 建立全新專案

1. **STEP1: 建立並啟動虛擬環境**
```bash
# 建立環境
py -m venv venv101

# 啟動環境 (Windows)
venv101\Scripts\activate
# 啟動環境 (Mac/Linux)
source venv101/bin/activate
```

> ps. 如果有成功，前面會多出 `(venv101)` 的標誌，或是用 which python 來檢查，如果顯示的路徑中有 `venv101`，就表示成功了。

**為什麼要建立虛擬環境？**

* 不同的系統可能用到的 python 版本不同，也可能用到的套件版本不同，建立虛擬環境可以避免這些問題。(例如 `python -3 -m venv venv101` 是裝 python3 的版本)
* 解決不同專案需要的套件版本不同問題。比方說專案 A 需要 django 3.2，專案 B 需要 django 5.0，如果不建立虛擬環境，這兩個版本會衝突。

2. **STEP2: 安裝 Django**
```bash
pip install django
```

或是建立一個 `requirements.txt` 裡面指定需要的套件和需要的版本，然後執行 `pip install -r requirements.txt`。例如：

```text
# 核心網頁框架
Django==6.0.8

# 影像處理套件 (使用 Django ImageField 時必備)
Pillow==12.0.0
```

3. **STEP3: 建立專案**
```bash
django-admin startproject proj101
```
其中 `proj101` 是專案名稱。可以自訂名稱，這會建立一個實際的目錄，裡面會有 `settings.py`, `urls.py` 等檔案。

4. **STEP4: 啟動伺服器**

```bash
cd proj101
python manage.py runserver
```

這時候進入 `http://127.0.0.1:8000` 可以看到火箭，表示安裝成功。
