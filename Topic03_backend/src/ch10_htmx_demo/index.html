HTMX Single File

HTMX 基礎非同步示範

點擊下方按鈕，HTMX 將向當前頁面發送 AJAX 請求，並僅選取隱藏的 HTML 片段插入到虛線框內。

點擊上方按鈕後，此處內容將被替換。

💡 教學與運作說明

⚠️ 瀏覽器安全性警告 (CORS Policy)

重要：如果您直接雙擊檔案開啟（網址為 file:///...），點擊按鈕將會無效。這是因為瀏覽器出於安全性限制，禁止本地檔案發送非同步（AJAX）請求。

🚀 如何在本地運行此範例？

您必須使用本地 HTTP 伺服器來載入此頁面：

  • 方法一 (推薦)：在終端機切換至本目錄，執行 python -m http.server 8000，接著瀏覽 http://localhost:8000。
  • 方法二：使用 VS Code，安裝 Live Server 擴充套件，並對本檔案右鍵選擇「Open with Live Server」。

🔎 這段代碼是如何運作的？

我們在左側的按鈕上宣告了三個 HTMX 屬性：

<button hx-get="index.html" 
        hx-select="#update-content" 
        hx-target="#result">
  • hx-get="index.html"：非同步請求當前這個 HTML 檔案本身。
  • hx-select="#update-content"：指明只提取回傳 HTML 中 ID 為 #update-content 的那個元素，其餘捨棄。這使得我們不需要另外準備一個檔案！
  • hx-target="#result"：將提取出來的元素放進 ID 為 #result 的區塊中。
✨
非同步載入成功！ 這是利用 hx-select 從同一個 index.html 中動態提取出來的隱藏區塊。
